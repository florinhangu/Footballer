# Game and editor images

The presentation uses screenshots from the actual No9: Day One game and the
separate No9Editor application.

## No9: Day One

`game/` contains the career home, fixture calendar, player attributes, weekly
training, world football, an original British English career story, and the 2D
and 3D match views. These are 1080×1920 desktop captures of the game's portrait
interface, taken from representative isolated career states using the real
screens and match renderer.

## No9Editor

`editor/` shows the standalone editor's club form, shirt and shorts galleries,
complete kit preview and stadium builder. The interface captures come from the
exported Windows application. The football-and-pencil icon is original vector
artwork used by the application.

The screenshots are presented without retouching. They show the game and editor
as separate applications.

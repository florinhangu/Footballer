# No9Editor 1.2.43

Published: 2026-11-05. Windows x86-64 standalone editor.

## Added

- Individually sourced stadium-capacity additions for 2,234 venues; 1,601 capacity values updated.
- 34 documented seating palettes, bringing documented venue palettes to 40.
- Documented real-name profiles for 147 domestic cups; five game-only counterparts remain explicit.

## Changed

- Licensed cup-name selection uses reviewed competition names; unlicensed defaults remain Country National Trophy.
- Capacity research rejects same-named venues in another country and stadiums that have not opened.
- Generated venue appearance can use documented seating palettes while preserving authored designs and the existing capacity rules.

## Removed

- Generic licensed domestic-cup placeholders were replaced wherever a real counterpart was verified.
- No editor features were removed.

## Verification

27,798 native checks at 1920 × 1080; 11,689 language observations without functional failures.

[Source reference](https://github.com/florinhangu/no9dayone/commit/2d4f2026e7d400ef2f4bfb788a0b1b4ba1519f10).

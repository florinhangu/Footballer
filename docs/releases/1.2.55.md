# No9Editor 1.2.55

Published: 2026-11-07. Windows x86-64 standalone editor.

Changes below cover the editor since the previous public release, 1.2.43.
The game itself is not distributed in this release.

## Added

- A Templates folder beside the executable, with six UV guides: short-sleeved shirt, long-sleeved shirt, shorts, socks, boots and NOVE ball.
- Sixty flat shirt templates, with the fabric overlay supplied separately.
- Custom PNG uploads for club and federation garments, matching Team-page shirts and separate long sleeves.
- Permanent custom logos for clubs, federations, leagues and competitions; PNG, JPEG, WebP and SVG imports.
- Portable projects and packs that embed custom artwork, including optional unassigned template collections.
- Playable NOVE ball designs and a standard black-and-white ball, selectable per league and competition, with a separate three-axis preview.
- A visual-only boot catalogue using the completed standard RGB design and 25 traditional palettes.

## Changed

- Short and long sleeves use separate UV artwork. Missing variants use plain primary-colour fabric instead of borrowing the other sleeve's texture.
- Custom kit PNGs preserve their original colours and branding. Automatic shirt crests, sponsors and manufacturer marks are suppressed; player names and numbers remain dynamic.
- Custom kits follow the existing one-edition replacement schedule. Separately uploaded crests remain until explicitly removed.
- The Team-page shirt follows the selected 3D design and colours, using matching custom 2D artwork or a front rendering of the actual custom 3D shirt.
- Duplicate archived entries for Benfica, 1860 Munich, Napoli and Fiorentina merge into their current clubs through old-save and package redirects. The catalogue retains 8,929 clubs and 407 reserve/B teams.
- Club locations and geographic defaults have been reviewed; stadium previews share the game's capacity rules and uniform stair widths. Documented geography is retained separately from explicit fallbacks.
- The complete club palettes have been reviewed against current-season sources where documented; publisher licence choices remain outside the public editor.

## Removed

- The four redundant archived club listings, while retaining their old identifiers as compatibility redirects.
- UV guides from playable model galleries; guides remain available in Templates.
- Automatic branding over custom shirt artwork.
- No public game build or game project is included.

## Verification

The exported standalone editor passed 234 checks at 1920 × 1080, with no functional failures. Focused custom artwork, package portability, club identity, ball, boot and seasonal scheduling tests also passed. All rendered tests ran silently.

This is desktop verification; Android and iOS device performance were not tested.

## Download

Open No9Editor.exe directly. Neither Godot nor the game is required. The executable contains its runtime, database, assets and template references and creates the Templates folder when first opened.

Templates.zip is also attached for authors who want the reference files separately. SHA256SUMS.txt contains the checksums of the executable, reference archive and licence notices.

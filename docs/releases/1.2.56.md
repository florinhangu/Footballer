# No9Editor 1.2.56

Published: 2026-11-08 (Europe/Bucharest). Windows x86-64 standalone editor.

## Added

- An Assets layout matching the reorganised authoring folders: 2D shirts, separate SS/LS shirts, shorts, socks, NOVE balls and boots.
- A shared 2D kit panel below the home, away and optional third 3D kits, with one 72 × 72 short-sleeved shirt and an Upload 2D button for each strip.
- Visible Upload logo buttons for clubs, federations, leagues and competitions. The existing league and competition SVG emblems are displayed by default.
- Numeric team filenames for uploaded kit artwork, such as 8004_home.png and 8004_away.png, in the corresponding category folder. Competition balls use the competition ID.

## Changed

- Every 3D garment displays its selected design inside its 72 × 72 selection button. The 3D upload controls remain separate.
- Short- and long-sleeved 3D shirts share a single short-sleeved 2D kit identity, chosen automatically from the 3D selection.
- Default club and federation kits use varied game models rather than a shared model-one placeholder.
- The Equipment templates library shows user-created and imported artwork; the standard boots remain available there. Team and competition forms retain their built-in design selectors.
- Balls retain rotation on all three axes. Other equipment rotates horizontally through 360 degrees.
- Boot previews use the match mesh, skin and idle pose. Their camera is fitted to both posed boots, with increased rendering resolution and an unchanged aspect ratio.
- Existing project artwork is exposed in the new folders without overwriting files edited manually in Assets. Immutable references and portable pack compatibility are retained.

## Removed

- The separate Custom directory from the authoring layout.
- The separate 2D preview beneath each shirt's 3D upload control.
- Standard shirts, shorts, socks and balls from the user template library; they remain available in the appropriate team and competition selectors.
- Unrestricted pitch/roll rotation for clothing and boots in the equipment library.

## Verification

1,159 focused checks passed with no functional failures. The standalone executable passed 113 checks at 1920 × 1080 with audio disabled. The checks cover the actual upload controls, numeric filenames, two/three-kit panels, 72-pixel selectors, default SVG emblems, portable artwork, the boot thumbnail and horizontal rotation. Source regressions also cover all 120 supplied SS/LS texture variants, seasonal kit rules and preservation of existing authoring files.

## Download

Open No9Editor.exe directly. Godot and the game are not required. The executable creates Assets and extracts missing references without replacing existing files. Assets.zip is also available separately; extract its contents into the Assets folder beside No9Editor.exe.

This release contains only the standalone editor. No game build or game project is distributed.

### Additional stadium verification

The individual corner-canopy test now passes 35 checks, covering all four corner
masks and the no-roof setting. Its earlier failure came from a stale fixture
that selected no-roof mode while expecting a canopy. The fixture uses the
individual-canopy mode; stadium geometry, capacity rules and the released

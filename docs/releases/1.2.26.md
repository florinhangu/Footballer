# No9Editor 1.2.26

Published: 2026-11-02. Windows x86-64 standalone editor.

## Added

- First published portable Windows editor build with its own runtime, database and assets.
- British English as the default, with a separate selectable Romanian catalogue.
- Independent shirt, shorts and socks model galleries, club-coloured thumbnails up to 72 × 72 and front/back 3D kit previews.
- Separate printing fonts, portable projects and shareable data packs.
- Club/federation forms and a live stadium-construction preview.

## Changed

- The desktop application uses the approved football-and-pencil identity and runs without a Godot installation.

## Removed

- No earlier public Windows release exists for a removal comparison.

## Verification

Standalone Windows x86-64 package; executable SHA-256 is supplied in the attached SHA256SUMS.txt.

# No9Editor 1.2.33

Published: 2026-11-05. Windows x86-64 standalone editor.

## Added

- 84 approved original crests: seven shapes with twelve shared patterns, including quartered squares.
- Globally unique entity IDs and compatibility mappings for older grouped competitions.
- Country Football Federation defaults, full continental organisation names and independent internal naming policies.
- Numbered domestic league tiers, lettered groups and country-flag palettes for all 213 national federations.

## Changed

- Crest interiors use the primary colour, symbols use the secondary colour and borders use the third colour or secondary fallback.
- International rule summaries use complete localised sentences, including the number of group matches.
- Full organisation names are retained in wide controls; compact controls use approved abbreviations.

## Removed

- The previous 22 crest artworks were replaced by the approved expanded set.
- Real official league/organisation names no longer appear as unlicensed defaults; their licensed reference names remain available internally.

## Verification

27,779 native editor checks; 398 international-rule localisation checks and 3,988 season/group compatibility checks.

[Source reference](https://github.com/florinhangu/no9dayone/commit/f50885061a8ce2ef4a8c87d7603c2ce568dd3b47).
